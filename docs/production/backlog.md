**M0 第 1 周并行准备**：负责人预约 12 名新用户及候补；Codex 准备主持词、记录表、A0 素材。选择线下同一台 iPhone 可避免每位受试者安装；若用外部 TestFlight，提前走审核，不让未完成的审核变成临时改用网页测试的理由。

M0-07 未通过不能领取 M1；一次 5 工作日调整须指出一个主要问题、重新冻结 build 并使用新的 12 人。无效实验先补证据，按第 0 章处理。

## 新任务或范围变更写法

每项记录：`任务 ID / 所属阶段 / 主责 / 输入 / 依赖 / 行为变化 / 验收 / 证据位置 / 未测项 / 状态`。新增工作先说明替换或推迟哪项、影响哪个实验，再更新 PRD 与 backlog；不用“顺便”加入 P1。
