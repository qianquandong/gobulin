## 一页摘要

**玩法**：下半屏点击锻造，上半屏英雄 Pip 自动战斗。每次锻造有固定的敲击预算（6–14 下），分配给三个区域：

- **Blade**：每点 +10% 伤害。点数跨过 4 和 8 时，攻击**形状**会变：Needle 单体刺击 → Broad 150° 横扫 → Great 360° 环斩。形状越宽，攻击越慢。
- **Hilt**：每点让攻击间隔缩短 7%。
- **Rune**：每点让符文触发更频繁。符文有三种：Ember 灼烧穿甲、Frost 减速、Spark 电弧破盾。

交付后，英雄的下一次攻击就用新形状。

**克制循环**：三类敌人特性各自惩罚一种形状。Swarm 成群，惩罚 Needle；Armor 护甲，惩罚 Broad；Guard 护盾，惩罚 Great。每种特性至少有两种锻造答案。失败报告用一句话说明主因和改进方向；玩家改锻后，在同样的资源水平下就能过关。这个循环已用模拟器在 1–20 关验证。

**为什么不只是又一个“锻造放置”**：已有产品（Auto Forge、Forge Master、Champion Forge 等）已经覆盖“锻造 → 装备 → 自动战斗”，Forgeland 也已经用了哥布林铁匠题材。本作的差异假设是：①**确定性的形状取舍**，没有稀有度与随机词条；②**敌人特性与锻造区域一一对应**的可学习克制；③**看得见的敲击变形**。这三点都需要首测验证（[1.5](01-positioning.md#15-差异假设到底和已有产品有什么不同)）。

**MVP**：20 关、3 种普通敌人、4 场 Boss、3 种形态、3 种符文、3 个设施（各 10 级）、离线 Loot Cart（8 h 上限）、Quick Forge、首购 / 材料包 / 宝石 / 免广告、3 个激励广告位。不做 PvP、公会、交易、抽卡、体力、插屏广告。

**当前批准范围：两周 M0 原型**。先按 [00 两周原型](00-two-week-prototype.md) 做首分钟反馈、3 类学习场景和 2 道无提示迁移题，外测 12 人后决定继续/调整/停止。后续第 3–12 周验证版（1–10 关）和再 6–8 周首测版均为条件计划；完整 P0 仍需约 17.5–25.5 程序人周，原型返工与补测另计（[12.3](12-scope-schedule-acceptance.md#123-里程碑依赖与工作量)）。

**分阶段指标（实验假设）**：M0：首分钟反馈 ≥9/12、理解取舍 ≥9/12、无提示迁移至少一题成功 ≥8/12 且总计 ≥14/24、自愿再试 ≥7/12。1–10 关验证版看理解、迁移、ARR 和 D1；D7 只描述，不作为该短内容版的通过/停止条件。完整首测版在内容足够时才启用 D7 ≥15% 闸门（[11](11-data-validation.md)）。

## 关键系统规格总表（输入 / 处理 / 输出 / 限制 / 异常）

| 系统 | 输入 | 处理规则 | 输出 | 限制 | 异常 | 详见 |
|---|---|---|---|---|---|---|
| 锻造 | Ore、可选 Rune Stone、预算 B、三区域点击 | 每次有效点击 +1 点；Blade 阈值决定形态；公式算出 H / I / W / N；节拍判定 Temper | 一把确定性的武器（进入 Rack） | 区域上限 12 / 6 / 5；点击最小间隔 0.15 s；同一时间 1 个会话 | 第 7 关前不足部分交付补助且不可套现，之后置灰；Rack 满时要求熔炼；中断恢复；Cancel 无损 | [4](04-forge-system.md) |
| Quick Forge | 已存 Pattern、同样材料 | 1.0 s 自动按 Pattern 加点 | 同分配武器，Temper 0 | Anvil Lv5 解锁；3（Lv10 时 4）个 Pattern | 预算多于 Pattern：剩余手动敲；没有符文石：置灰 | [4.8](04-forge-system.md#48-自动化quick-forge) |
| 熔炼 / 重铸 | 一把未上锁的武器 | 返还 floor(0.8 × ore_paid)，不含教程补助；重铸 = 熔炼 + 新锻，同元素保留符文石 | Ore；新武器 | 上锁不可熔炼 | 5 s 内可撤销熔炼 | [6.7](06-gear-builds.md#67-旧装备回收收藏与资源返还) |
| 战斗结算 | 装备武器、敌人配置、英雄 HP | 20 Hz 逻辑：前摇 → 命中帧 → 形状判定 → 护盾 → 护甲（下限 20%）→ 符文 | 伤害、胜负、失败主因 | 同时最多 6 个攻击者；普通关 90 s、Boss 段 120 s | 超时判负；目标在前摇中死亡则挥空 | [5.3](05-combat.md#53-攻击动画命中逻辑视觉特效三层分离)、[5.5](05-combat.md#55-伤害公式与单位) |
| 换装 | Rack 中的武器 | 当前命中帧结算后生效，0.5 s 换装，充能清零 | 新装备 | 3 s 冷却 | 前摇中交付：先用旧武器结算这一击 | [5.4](05-combat.md#54-武器何时装备何时生效能否战斗中替换) |
| 失败与重试 | 失败事件与本场统计 | 按顺序判定主因（Guard ≥ 40% → Armor ≥ 40% → 被围 ≥ 5 → 超时 → 其他） | 失败报告；Forge / Retry；5 s 后练习模式 | 无次数限制、不扣资源 | 连续 3 次失败给出配方 | [5.8](05-combat.md#58-失败处理与重复挑战) |
| 设施升级 | Coins | 按费用表立即升级 | 预算 / MD / HP 提升 | Lv1–10；部分等级有关卡门槛 | Coins 不足或被关卡锁住：置灰并说明 | [7.3](07-economy.md#73-前-10-级锻造设施) |
| 首通奖励 | 首次通关事件 | 按关卡公式发放 | Coins / Ore / Stones / Gems、解锁 | 每关一次 | 符文石溢出转为 Coins | [7.4](07-economy.md#74-前-20-关示例进度与材料需求) |

| 内购发放 | StoreKit 2 交易 | 本地验签 → 发放 + 存档 → `finish()` | 权益与道具 | 商品各有购买上限 | 待处理、中断补发、退款撤销 | [10.7](10-content-art-tech.md#107-购买与恢复) |

## 术语表

| 术语 | 说明 |
|---|---|
| Strikes / 预算 | 一次锻造可敲的次数 |
| Bp / Hp / Rp | Blade / Hilt / Rune 点数 |
| MD | 金属基础伤害，由锻造时的 Furnace 等级决定 |
| H / I / W / N | 每击伤害 / 攻击间隔 / 前摇 / 符文每 N 次挥砍触发 |
| Temper | 本次锻造的 Perfect 次数，每点 +1% 伤害，上限 10 |
| Rack | 武器架（3 → 4 → 5 格） |
| Loot Cart | 按时间累积的离线 / 在线收益，8 h 上限 |
| Quick Forge / Pattern | 按保存的分配自动锻造（Temper 0） |
| ARR | 对症响应率，核心验证指标（11.2） |
| 期望状态 | 设计假定玩家通关某关时的设施等级 |
