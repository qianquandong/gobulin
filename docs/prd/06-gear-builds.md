# 6. 装备与构筑

## 6.1 MVP 武器

**[决定]** MVP 只有一种武器族：剑。差异来自**形态 × 金属 × 符文**三个维度。不做多种武器类型（斧、锤、矛），用来控制动画成本（[10.2](10-content-art-tech.md#102-复用方案让武器差异看得见同时控制成本)）。

| 维度 | 取值 | 玩家看到的差异 |
|---|---|---|
| 形态（Blade 点数决定） | Needle（0–3）/ Broad（4–7）/ Great（8–12） | 刀身轮廓、攻击动作、命中形状（细线 / 扇形 / 圆环） |
| 金属（Furnace 等级决定） | Copper（Lv1–3）/ Iron（4–6）/ Steel（7–9）/ Moonsilver（10） | 调色板与刀光颜色；MD 10 → 46 |
| 剑柄缠绕（Hilt 点数） | 0–6 圈缠绳 | 剑柄上的缠绳圈数，以及挥砍速度 |
| 符文（Rune 点数 + 元素） | 无 / Ember / Frost / Spark，亮度 1–5 | 护手处的符文宝石颜色、亮度，以及触发特效 |

武器名称：`{metal} {formNoun}`，例如 *Copper Needle*、*Iron Broadsword*、*Moonsilver Greatsword*（最长 21 字符）。符文不写进名称，以图标与标签显示，用来控制小屏长度。

## 6.2 符文

| 符文（英文名） | 解锁 | 触发效果（每 N = 6 − Rp 次挥砍） | 擅长 | 不擅长 | 视觉 |
|---|---|---|---|---|---|
| **Ember** | 首通关卡 5（Queen Mushla） | 点燃本击造成伤害的目标：3 s 内共 150% H，无视护甲与护盾，不叠加，可刷新 | Armor（Shellback、Ironhide） | 护盾目标（灼烧必须由一次**造成伤害**的命中施加） | 橙色宝石，目标身上着火，橙色数字 |
| **Frost** | 首通关卡 10（Ironhide） | 本击原始伤害 ×1.3；被伤害的目标 Chill 3.5 s（攻击、移动、召唤、重击都放慢到 ×0.65） | Boss 与高伤害波次（减少受到的伤害） | 纯输出比较 | 青色宝石，目标结霜，青色数字 |
| **Spark** | 首通关卡 12 | 主目标 + 3u 内最近的 2 个敌人，各受 60% H；**贯穿护盾**（打掉 1 点并照常造成伤害）；本击被全部挡下也会触发 | Guard（Sprite、Thornwarden）、成群 | 高护甲（每道电弧都要扣护甲） | 黄色宝石，电弧连线，黄色数字 |

### 6.2.1 材料（与构筑相关的部分）

|---|---|---|---|
| Ore | 每次锻造或重铸的成本，决定“试一把新构筑”的代价；熔炼返还 80%，所以试错的净成本约 20% | 首通、Loot Cart、熔炼返还 | [7.1](07-economy.md#71-资源清单) |
| Rune Stones | 给武器装上符文（通用，不分元素）；同元素重铸保留，换元素才消耗 | 首通 5 / 8 / 10 / 12 / 15 / 20、Loot Cart、每日广告 | [4.3](04-forge-system.md#43-材料与成本) |

## 6.3 构筑：可用的打法

> 获取路径中的关卡号、期望设施等级来自 [7.5](07-economy.md#75-完整资源路径初始装备首次-boss第一次构筑转型)。“模拟证据”来自 `balance_sim.py`，在期望状态下取 3 个种子。

| 构筑（玩家社区可能的叫法） | 典型分配 | 优势 | 弱点 | 适用敌人 | 获取路径 | 模拟证据（胜场 / 剩余 HP） |
|---|---|---|---|---|---|---|
| **Sweeper** 宽刃横扫 | Broad，B4–7 / Hilt 拉满 | 前方扇形清群、速度中等、能压住护盾；最全能 | 护甲：单击 13–26 被甲 10–20 削掉大半 | Swarm、Guard、混合波 | 关卡 3 教程（预算 7） | 关卡 3：3/3、74%；关卡 11：3/3、48%；关卡 20 重刃版 B7/H6：3/3、34% |
| **Spinner** 巨刃环斩 | Great，B8 / 剩余点数给 Hilt | 360° 一圈全中；单击 31–71，对甲群收益最高；被围时清怪最快 | **护盾**：间隔 > 1.5 s 时打不破护盾，对 Sprite 和 Thornwarden 伤害为 0 | Swarm + Armor 混合，例如关卡 7、16、18 | Anvil Lv3（通关 6 后，预算 8） | 关卡 7：3/3、80%；关卡 16：3/3、90%；关卡 8（3 只 Sprite）：0/3 |
| **Ember Needle** 灼烧刺剑 | Needle，B3 / H1–4 / R3 Ember | 单体最高；灼烧无视护甲，是对付 Ironhide 的最佳单挑 | 被群怪包围时一次只能打一个 | 单体护甲、Boss（Ironhide） | 关卡 5 得到符文石 → 教程锻造 #3 | 关卡 6：3/3、40%；关卡 10（Ironhide）：3/3、34%，纯 Needle 0/3 |
| **Spark Needle** 电击刺剑 | Needle，B3 / H5–6 / R3–4 Spark | 快速破盾，电弧顺带清周围；对 Guard 群和 Thornwarden 最佳 | 高护甲时电弧伤害被削弱 | Guard、Guard + 小群 | 首通 12 解锁 Spark | 关卡 15：3/3、70%；关卡 17：唯一 3/3（16%）；关卡 19：3/3、52% |
| **Frost Guard** 冰霜减速 | Broad 或 Great + Frost R1–4 | 放慢敌人攻击与 Boss 重击 → 受到的伤害降低 | 输出不如其他符文 | Boss、高伤害波次 | 首通 10 解锁 Frost | 关卡 15：Broad + Frost 3/3、69%；关卡 16：Great + Frost 3/3、90% |

**[决定] 构筑设计约束（防止通吃）：**

1. 每种形态至少有一种敌人特性能让它**失败**：Needle 输给 Swarm（关卡 3、5）；Broad 输给 Armor（关卡 6、7、Ironhide）；Great 输给 Guard（关卡 8、Thornwarden）。
2. 每种特性至少有**两种**锻造答案（一种靠形态，一种靠符文）：Swarm → Broad / Great / Spark；Armor → Great / Ember；Guard → Needle / Broad / Spark。
3. 没有可以付费购买的专属形态或符文（[9.5](09-monetization.md#95-是否破坏构筑选择逐项评估)）。

### 6.3.1 双武器换装（关卡 14）

关卡 14 的组成：[Shellback ×3] → [Sprite ×4] → [Shellback ×2 + Sprite ×2]。最佳单一构筑 Broad + Ember 只有 2/3 胜；带 Great 与 Needle + Spark 两把武器，第 1 波用 Great，第 2 波起换成 Needle + Spark，可以 3/3 胜、剩余 HP 45%。这是“推荐标签 + 一次换装”的教学关，换装在 1 s 的波次间隔里完成，不需要战斗中的快速操作。

## 6.4 稀有度与随机词条（决定）

**[决定] MVP 不做稀有度，也不做随机词条。**

| 理由 | 说明 |
|---|---|
| 支持核心假设 H1 | 结果 100% 来自玩家分配，失败时玩家知道是哪个选择错了，而不是“运气不好” |
| 防止稀有度压倒选择 | 没有“紫色 Needle 比白色 Great 更好”的情况；同金属同分配的武器只差 Temper（≤ 10%） |
| 平衡与测试成本 | 一名策划无法平衡词条池；确定性结果可以用 `balance_sim.py` 全覆盖验证 |
| 坏结果处理 | 不存在“锻坏”。交付前有完整预览和对比（[8.3](08-ui-ux.md#83-锻造选择与交付对比)）；Cancel 无损；Reforge 只花约 20% Ore |

**若 P2 考虑加入随机性**，前置条件：首测数据显示玩家在第 7 天后锻造频率明显下降（[11](11-data-validation.md)），并且新增随机性不能改变形态与符文。候选规格（**不在 MVP 内**）：

| 项 | 候选值 |
|---|---|
| 名称 | Masterwork |
| 触发 | 手动锻造且 Temper = 10 时，固定获得 1 条（不靠概率） |
| 内容 | 从 3 条中**选 1 条**：+5% 伤害 / −3% 间隔 / 符文 N − 1（最低 1） |
| 重铸 | Reforge 时可以重新选；不额外收费 |
| 上限 | 每把武器 1 条 |

## 6.5 构筑使用率预期

模拟中，每关剩余 HP 最高的构筑（关卡 1–20）：

| 形态家族 | 最佳关卡 | 关数 |
|---|---|---|
| Broad（含 + Ember / + Spark） | 1、2、3、4、5、8、9、11、12、13、20 | 11 |
| Needle + 符文 | 6、10、15、17、19 | 5 |
| Great（含 + 符文） | 7、16、18 | 3 |
| 换装 | 14 | 1 |

**[假设] 目标使用率**（按装备时长计算，关卡 8–20）：没有任何形态超过 60%，每种形态 ≥ 15%。Great 在 P0 内容中占比偏低，原因是 Bramble Deep 区域 Sprite 较多；P1 的 Rustfang Mines（21–30）以 Armor 为主，会提高 Great 的使用率。指标定义见 [11.3](11-data-validation.md#113-构筑与进度指标)。

## 6.7 旧装备回收、收藏与资源返还

| 功能 | 规则 |
|---|---|
| 熔炼 Smelt（`btn_smelt`） | 返还 floor(0.8 × 该武器所付 Ore)；Rune Stone 不返还；需要确认 `smelt_confirm` “Smelt {name}? You get {ore} Ore back.” |
| 重铸 Reforge | 等价于“熔炼 + 新锻”，同元素保留符文石（[4.3](04-forge-system.md#43-材料与成本)） |
| 上锁 Lock（`btn_lock`） | 上锁的武器不能熔炼，也不会出现在“武器架已满”的熔炼列表中 |
| 收藏 Codex | 12 格图鉴（3 形态 × 无 / Ember / Frost / Spark）。首次手动锻造对应组合时点亮该格并奖励 20 Gems，一共 240。Quick Forge 不点亮（鼓励手动尝试新组合）。每格显示一句英文用法提示（`codex_tip_*`） |
| 武器架上限 | 3 / 4 / 5 格（通关 8、15 时扩展）。**不出售武器架格子**（[9.5](09-monetization.md#95-是否破坏构筑选择逐项评估)） |
| 返还上限与防刷 | 熔炼返还低于锻造成本（80%），反复锻造 + 熔炼必然净消耗 Ore，不存在套利 |
| 误熔炼 | 熔炼后 5 s 内可以点 Toast 上的 **Undo**（`btn_undo_smelt`）恢复武器并扣回返还 |
