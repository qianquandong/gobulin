# 3. 前 10 分钟完整脚本

> v0.2：首个“敲宽 → 横扫”的反馈提前到 60 秒内。下文是后续正式版的首局脚本；M0 只做首分钟和独立场景，范围与测试流程以 [两周原型](00-two-week-prototype.md) 为准。时间为待实机验证的设计目标，不是模拟器已验证的游玩时长。

## 3.1 目标

| 目标 | 时间目标 | 验收 |
|---|---|---|
| 开始操作 | 可交互后 10 s 内 | 已看到敌人，可以点铁砧；无标题等待或长对白 |
| 第一次形态改变 | 60 s 内 | 玩家亲手锻出 Broad，交付后实际命中 ≥3 个目标 |
| 理解第一层取舍 | 首分钟后 | 宽刃多目标、动作更慢；暂不讲设施、货币、节拍 |
| 后续学习 | 1–10 min | 逐步经历正式关卡、Guard、Ember、Great；不强求每人十分钟学完全部系统 |

**首局保护规则：**

1. 通关 7 前不显示广告、商店入口或付费提示。设施升级只开放下表/7.5 的当前教程目标，防止 Coins 误花；锻造分配可自由尝试。
2. 开场演示使用隔离状态：MD 10、预算 7、HP 100、Temper 3，初始提供 Needle B2/H2。资源不扣、不发首通或 Codex 奖励；演示武器不进入正式 Rack，不能熔炼。退出或完成后初始资源仍是 C0/O20/S0。
3. 演示中英雄 HP 最低为 1；敌人按真实形状/伤害结算。只帮助展示第一次因果关系，不把这个受保护场景计入自主策略指标。
4. 进入正式流程后沿用武器与战斗公式；关卡 1–2 的代表性模拟均能过关，但不据此承诺所有操作都不会失败。关卡 3 的教程 Brace：HP ≤60% 时伤害 −80%，持续到新武器交付或本次挑战结束；允许直接退出/重试。
5. 只在首次敲击说明触控区域，其余不锁定 B/H/R 配方。Ember 学习可以给方向，不强制具体点数。教程阶段材料不足按 [7.6.1](07-economy.md#761-教程材料兜底) 处理。

## 3.2 逐段脚本

| 目标时间 | 画面与动作 | 反馈与文案 | 资源及验证边界 |
|---|---|---|---|
| 0:00–0:10 | 直接看到 Pip 用 Needle 打群怪，铁砧可点 | `tut_07`、`tut_08`：提示群怪和敲宽剑刃 | 隔离演示，无经济 |
| 0:10–0:40 | 玩家敲 Blade，跨 4 变 Broad；剩余点数可给 Hilt；Deliver | `forge_form_broad`、`tut_09`；对比命中数与间隔 | 有真实分配和取舍，不自动交付 |
| 0:40–1:00 | 英雄横扫实际命中至少 3 个；允许继续试 | `tut_10`、×N、加强轮廓 | 未看到效果就重置演示敌人，不虚构 ×N；记录是否超过 60 s |
| 1:00–3:30 | 结束演示，进入正式关卡 1–3；自由锻首把武器（参考路径为 Needle，已掌握宽刃可直接选 Broad），通关 2 后升 Anvil 2 | 复用 `tut_02`、`tut_04–06`；已懂的区域不重复全屏教学 | 沿用 7.5 步骤 0–6 的账本，通关 3 后 C62/O27；允许自由分配，实际余额可能不同 |
| 3:30–5:30 | 升 Furnace 2，关卡 4 看 Guard，关卡 5 Boss Gate 与 Queen | `tut_11–13`、`boss_queen_hint`；玩家可以换装 | 沿用步骤 7–9；参考通关 5 余额 C192/O43/S2 |

| 7:30–9:30 | 升 Anvil 3，开放预算 8 与 Great；自由决定如何应对关卡 7 | `tut_18` 改为说明可造更大剑；不强制 Blade ×8 | 参考步骤 13–15，通关后 C149/O50/S1；Rack 满才教熔炼 |

## 3.3 玩法展示与自主理解分开

- 首分钟只证明形态变化可见；后续教学展示 Needle/Broad/Great/Ember 的差别。
- 主持人不在学习后立即给带答案的问卷。先做无提示迁移，再要求解释，再给选择题；避免把记住刚出现的文字当作理解。
- 正式前十分钟完成率、M0 迁移成功率、E-1 固定状态试玩结果分组记录，不能混算。资源、解锁和提示配置见 [11](11-data-validation.md)。

## 3.4 分支与异常

| 情况 | 处理 |
|---|---|
| 演示中重启 | 重做演示，不携带演示物品或奖励进入正式存档 |
| 已经自由锻出 Broad | 跳过重复宽刃指导，仍记录第一次真实多目标反馈 |
| 正式关卡失败 | 不扣资源，保留 Forge/Retry；提示依正式规则，迁移测试依专用开关隐藏 |
| 通关 7 前反复试锻导致材料不足 | 交付时补足 Ore/已解锁符文所需 Stone，补助不入钱包、不计入可返还成本；不用广告或等待救场 |
| 未选择 Ember/错误分配 | 允许失败和自主重试，不能将免费重试描述成免费锻造；正式锻造仍按材料规则结算 |
| Rack 满或全部上锁 | 交付前选择可熔炼武器；拒绝则保留坯料；先解锁才能熔炼，不自动删除 |
| 首局超过十分钟 | 不强推下一教学节点；按实际时间记录，允许退出后继续 |
